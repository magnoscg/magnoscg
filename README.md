# Hi, I'm Oscar

Senior iOS Engineer building production apps and developer tools with Swift,
SwiftUI, and Clean Architecture.

I care about code that stays understandable as products grow: explicit
boundaries, predictable navigation, strict concurrency, useful tests, and
interfaces that remain accessible and responsive across Apple platforms.

## What I work with

- **Apple platforms:** Swift 6, SwiftUI, UIKit, Observation, SwiftData,
  StoreKit 2, WidgetKit, App Intents
- **Architecture:** Clean Architecture, MVVM, Router/Coordinator, modular SPM
  packages, dependency injection
- **Engineering quality:** Swift Testing, XCTest, strict concurrency,
  accessibility, performance profiling, CI/CD
- **Developer tooling:** Go and TypeScript CLIs, MCP servers, code generation,
  documentation automation

## Current focus

- Shipping and evolving production iOS apps
- Building reusable architecture and scaffolding for Swift teams
- Creating local-first developer tools for AI-assisted engineering
- Turning product and engineering decisions into durable documentation
